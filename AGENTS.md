## Strict Rules for Component Modifications

1. **Prompt-Scoped Modifications Only**:
   - Only modify the components, styling, or functionality explicitly asked for in the user prompt.
   - Do NOT modify or refactor any other files or components outside the prompt's scope.

2. **Maintain Overall Functionality**:
   - Keep the overall architecture, backend APIs, data models, state management, and user flows identical.
   - Do not break existing features, routes, or responsive behaviors.

3. **Targeted & Precise Edits**:
   - Make atomic, minimal, and non-destructive changes.
   - Preserve existing props, handler functions, and documentation.
